# jobsfromthesource

A project to read job ads directly from company websites.

## Overview

**jobsfromthesource** is a job aggregation tool designed to:

1. Find lists of employers from reputable sources.
2. Find job listing endpoints for as many sources as possible (e.g. Workday, Greenhouse, Lever, official company career pages).
3. Extract job listings and place them into a searchable, refreshable database.

The ultimate goal is to create a continuously refreshed database of job opportunities sourced directly from employers.

---

# Design

The project is organised as a series of processing pipelines.

```
main.py
│
├── p01_foundational_database
│   └── Create files containing lists of employers
│
├── p02_career_discovery
│   └── Discover company websites and job listing endpoints
│
├── p03_job_aggregation
│   └── Extract and enrich job listings into a database
│
├── search_tools
│   └── Search and database utilities
│
└── definables
    └── Project configuration files
```

# Pipeline 1 — Foundational Database

## `p01_foundational_database`

Creates employer lists from reputable sources.

Structure:

```
p01_foundational_database
│
├── __init__.py
│
├── p01_0_main.py
│   └── Runs p01_1 through p01_2
│
├── p01_1_providers.py
│   └── Functions for extracting employer names from official lists
│
├── p01_2_employer_tables.py
│   └── Generates employer tables using p01_1_providers.py
│
└── p01_outputs
    └── Output files used as input for p02
```

# Pipeline 2 — Career Discovery

## `p02_career_discovery`

Finds job listing endpoints from employer websites.

Structure:

```
p02_career_discovery
│
├── __init__.py
│
├── p02_0_main.py
│   └── Runs p02_1 through p02_6
│
├── p02_1_searxng_client.py
│   └── SearXNG search setup
│
├── p02_2_company_search.py
│   └── Generates possible company domains using SearXNG
│
├── p02_3_website_validator.py
│   └── Uses AI to determine the correct company website
│
├── p02_4_career_page_discovery.py
│   └── Generates candidate job listing endpoints
│
├── p02_5_resolve_ai_site_candidates.py
│   └── Verifies job listing endpoints generated by AI
│
├── p02_6_call_job_endpoint_repair.py
│   └── Finalises remaining job listing endpoints
│
├── job_endpoint_repair.py
│   └── Supporting functions called by p02_6
│
└── p02_outputs
    └── Output files used as input for p03
```

# Pipeline 3 — Job Aggregation

## `p03_job_aggregation`

Extracts job listings and stores them in a searchable database.

Structure:

```
p03_job_aggregation
│
├── __init__.py
│
├── p03_1_create_jobs_table.py
│   └── Extracts jobs from company endpoints and stores them in Supabase
│
├── p03_2_run_table_creation.py
│   └── Runner script for p03_1
│
├── p03_3_enrich_job_details.py
│   └── Adds missing job information:
│       - salary
│       - location
│       - advert text
│       - posting date
│
├── p03_4_run_enrich_job_details.py
│   └── Runner script for p03_3
│
└── p03_outputs
    └── Output files generated during processing
```
